# Neo Casette

**Neo Casette Interactive** is a mobile-first MSX2 emulator interface project focused on combining the character of the original MSX experience with a clean, modern touch interface.

> **Project status:** Prototype / work in progress.  
> Features, architecture, compatibility, and interface details may change during development.

## Project goals

Neo Casette is being designed around a few core ideas:

- A practical MSX2 experience on modern mobile devices.
- A full on-screen MSX keyboard for computer use.
- A dedicated game-controller mode with configurable touch controls.
- Disk handling that remains simple while still recalling the physical feel of using an MSX.
- Portrait and landscape layouts designed intentionally for each orientation.
- An interface inspired by original MSX hardware and interaction, without attempting to reproduce any particular machine exactly.

## Current prototype

The current repository contains an evolving interactive front-end prototype. It is being used to develop and test the interface, control layouts, display modes, disk handling, and mobile interaction before the emulator implementation is considered complete.

The project should therefore not yet be treated as a finished or fully compatible MSX2 emulator.
